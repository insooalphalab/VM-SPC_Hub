# VM-Hub — 역할 분할 설계

기존 VM-SPC Core 한 곳에 몰려 있던 수집 · 검증 · 판단 · 화면 · 뉴스를 역할 5개로 나눈다.
데이터를 모으는 네 역할이 정리본을 내면, 코어가 검증된 규칙으로 판단해 사용자에게 리포트 한 편으로 보낸다.

```
2 국내 시장 ─┐
3 해외 시장 ─┤   exchange/{역할}/{날짜}/summary.json · summary.md
4 매크로   ─┤ ──────────────────────────────────────────────▶  1 코어: 판단(검증된 규칙만) → 리포트(페이지 + 텔레그램)
5 뉴스     ─┘                                                    새 지표 · 아이디어 → 사전 등록 → 백테스트 → 등급
```

## 역할

| 역할 | 하는 일 | 내보내는 것 | 출발점(복사 원본) |
|---|---|---|---|
| **1 코어** | 검증(사전 등록 → 백테스트 → 등급) · 판단 · 최종 리포트 | 아침 · 마감 리포트(HTML + 텔레그램), 검증 기록 | `VM-SPC_Core`의 research/ · docs/검증 · scenario/(판단 · 화면) · vm_spc/notify_telegram.py |
| **2 국내 시장** | 일봉 · 기술 지표 · 투자자 수급 · 프로그램 · 신용 · 공매도 · DART 공시 · 코스피 장세 | 장세 상태, 대량 복귀일 여부, 오늘 규칙 충족 종목, 보유 종목 상태, 원자료 위치 | `VM-SPC_Core`의 vm_predict/ · stock_track/ · dart_events/ · scenario/screen.py 수집부 + `KIS_auto` 장중 수집 |
| **3 해외 시장** | 미국 지수 · 반도체(SOXX 등) · 대형주 · 미국 ETF 방향 예측 | 미국 마감 요약, ETF 예측, 일별 CSV | `VM-SPC_Global` |
| **4 매크로** | 금리 · 환율 · 유가 · 신용스프레드 · DRAM/NAND 현물가 | 매크로 일별 표 · 변화 요약 | `KIS_auto/월간_매크로섹터분석.py` + `VM-SPC_Core/data/_market/usdkrw_yahoo.csv` (가장 새로 키울 부분) |
| **5 뉴스** | 텔레그램 리서치 채널 수집 · 이슈 빈도 순위 · 주요 뉴스 10줄 · 리포트 흐름 | 하루 주요 뉴스, 리포트 목표가 상향 · 하향, 날짜별 원문 Markdown | `VM-SPC_Core/reports/`(news_digest.py · export_md.py · parse.py · tg_*) |

판단 원칙: 2–5는 방향을 판단하지 않는다(데이터 + 서술). 1 코어만 판단하며, 검증 등급이 붙은 규칙만 판단에 쓰고 나머지는 "참고"로 리포트 아래쪽에 둔다.
지금까지 검증으로 수급 · 뉴스 · 증권사 리포트는 이후 방향을 알려 주지 않았다(VM-SPC Core 9.15 · 9.106 · 9.272 · 9.275). 해외 · 매크로는 아직 검증 전.

## 데이터 위치 (전환 기간 — 읽기만)

| 데이터 | 지금 위치 | 넘겨받을 역할 |
|---|---|---|
| 790종목 일봉(2016 – ) | `..\VM-SPC_Core\data\_long_history\` | 2 |
| 투자자 일별 · 프로그램 · 신용 · 공매도 | `..\VM-SPC_Core\data\_investor_detail\` · `_program\` · `_credit\` · `_short\` | 2 |
| DART 재무 · 공시 · 상장주식수 | `..\VM-SPC_Core\data\_dart\` | 2 |
| 텔레그램 원문 · 리포트 · 뉴스 표 | `..\VM-SPC_Core\data\_reports\` (raw/ · reports.csv · news.csv) | 5 |
| 미국 일봉 · 글로벌 비교 CSV | `..\VM-SPC_Global\data\` (for_core/ 포함) | 3 |
| 환율 | `..\VM-SPC_Core\data\_market\usdkrw_yahoo.csv` | 4 |
| 보유 · 관심 종목 | `..\VM-SPC_Core\scenario_targets.json` (비밀 — 커밋 금지) | 1 · 2 |

수집 담당은 데이터마다 **한 곳**만 둔다. 같은 데이터를 두 역할이 따로 받지 않는다.
텔레그램 로그인 세션 파일(`..\VM-SPC_Core\state\telegram_reports.session`)은 두 곳이 동시에 쓰면 충돌한다 — 5가 수집을 넘겨받기 전까지 5는 Core가 받은 원문을 읽기만 한다.

## 예약 시각 (전환이 끝난 뒤 목표, KST)

| 시각 | 역할 | 내용 | KIS |
|---|---|---|---|
| 07:00 화 – 토 | 3 해외 | 미국 마감 수집 · 예측 | 씀 |
| 07:20 | 4 매크로 | 금리 · 환율 · 유가 갱신 | – |
| 07:40 | 5 뉴스 | 밤사이 · 아침 시황 정리 | – |
| 08:00 | 1 코어 | **아침 리포트** | – |
| 15:50 | 5 뉴스 | 장중 · 마감 시황 정리 | – |
| 16:30 평일 | 2 국내 | 일봉 · 수급 · 장세 · 규칙 충족 종목 | 씀 |
| 17:15 | 1 코어 | **마감 리포트** | – |

KIS를 쓰는 2 · 3은 시간이 겹치지 않는다(토큰 발급 5분 1회). 각 역할의 토큰 캐시는 자기 폴더 `state/`에 둔다.
전환 기간에는 기존 VM-SPC_Core(16:30) · VM-SPC_Global(07:00)이 이 자리를 쓰고 있으므로, 새 역할의 KIS 수집은 그 시각과 10분 이상 떨어뜨리거나 기존 결과를 읽는다.

## 전환 순서

| 단계 | 할 일 | 상태 |
|---|---|---|
| 0 | VM-SPC_Core 미커밋 작업 커밋(c341a11) | 완료 |
| 1 | 이 폴더 · 설계 · exchange 형식 · 역할별 지침 | 완료 |
| 2 | 5 뉴스: news_digest를 10줄 형식 · 채널 빈도 순위로, exchange 출력 | 대기 |
| 3 | 3 해외: VM-SPC_Global 결과를 exchange로 내보내기 | 대기 |
| 4 | 2 국내: 장세 · 대량 복귀일 · 규칙 충족 · 보유 상태를 exchange로(처음엔 Core 결과 읽기, 다음에 수집 이관) | 대기 |
| 5 | 4 매크로: 일별 매크로 표 새로 만들기 | 대기 |
| 6 | 1 코어: exchange를 읽어 아침 · 마감 리포트 | 대기 |
| 7 | 며칠 나란히 비교 → 기존 예약 작업을 사용자가 하나씩 정리 | 대기 |

각 단계는 그 역할 폴더에서 새 세션을 열어 진행한다. 단계가 끝나면 이 표의 상태를 고친다.
